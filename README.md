# MSU-MCEST Innovation Band

A responsive, single-page website for exploring a sample band repertoire and sending performance booking requests.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript with no build step.

## Update before launch

- Replace the illustrated performance scenes with real, approved band photos.
- Confirm the sample song list and current arrangements with the band.
- Replace the clearly labeled testimonial placeholder with an approved, genuine testimonial.
- Update the band description, lineup, and booking contact as needed.

## Booking requests

The booking form prepares an email addressed to `markericgenosa2@gmail.com` in the visitor's default email app. The visitor reviews and sends the message there; submissions are not stored by this static website.
