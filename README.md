# MSU-MCEST Innovation Band

A responsive, single-page website for learning about Innovation Band, exploring its musical styles, and sending performance booking requests.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript with no build step.

## Update before launch

- Add approved band and performance photos or video.
- Add a verified, current song list and arrangements when ready.
- Replace the testimonial placeholder with approved, genuine quotes when available.
- Review member names, roles, and band history for accuracy before publication.
- Replace generic video captions with event names and dates when confirmed.

## Booking requests

The centered booking form prepares an email addressed to `markericgenosa2@gmail.com` in the visitor's default email app. The visitor reviews and sends the message there; submissions are not stored by this static website. Booking details on the site request advance notice of 2–3 weeks, and the venue must have an electricity source.
